升官等記憶樹｜tb-2026-10-20a_Claude（完整候選版）

【先選一種使用方式】
A. 不想部署、直接離線用：開啟「離線單檔_升官等記憶樹_tb-2026-10-20a_Claude.html」。
   此檔已包含全部三科與35題申論，不依賴網路抓資料，不註冊 Service Worker。
   在某些 file:// 瀏覽器內，本機儲存可能受限；要保留進度請定期按「匯出備份」。
B. 想測 PWA：將整個 ZIP 解壓後的 index.html / sw.js / manifest.webmanifest / data / icons
   原路徑放到獨立 HTTPS 測試站。**尚未授權覆蓋 GitHub 正式站**。

【20a 新功能】
綠色虛底線條號可點開全文；「法條」分頁查條文、遮住背誦；各處 🔊 朗讀（底部控制列可調語速與停頓）；申論答案「挖空回想」。
朗讀用裝置內建語音，手機需安裝中文（台灣）語音；明細見 docs/變更清單_tb-2026-10-20a_Claude.md。

【使用流程】
申論訓練 → 先寫草稿 → 可啟動限時計時 → 逐段揭露 → 校訂答案 → 自我核對 → 註記錯漏 → 評分安排複習。

【備份／還原】
右上「匯出備份」下載包含 tb-v1、tb-essay-draft-v1、tb-essay-errors-v1 的本機 JSON。
把 JSON 傳到另一裝置後按「匯入備份」選擇。衝突同題以匯入版本為準，不相干題目保留。
備份可能含個人讀書草稿，請勿公開分享；系統不會上傳這份檔案。

【現行版本安全】
這一份是 20a 候選版（以 i 版為底），正式 d 與 e～i 都未覆蓋。升官等考試 2026-11-07～08。
