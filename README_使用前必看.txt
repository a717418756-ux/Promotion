升官等記憶樹｜tb-2026-10-20e（正式版，2026-10-20 上線）

【使用方式】
直接開 GitHub Pages 網址；首次載入後可離線使用（Service Worker 快取）。

【20a～20e 新功能】
綠色虛底線條號可點開全文；「法條」分頁查條文、遮住背誦；各處 🔊 朗讀（底部控制列可調語速與停頓）；申論答案「挖空回想」。20b～20d 加入勤務條例、警職法、通保法、家暴法、聯繫辦法等法規全文（共26部）。
朗讀用裝置內建語音，手機需安裝中文（台灣）語音；明細見雲端變更清單_tb-2026-10-20e_Claude.md。

【使用流程】
申論訓練 → 先寫草稿 → 可啟動限時計時 → 逐段揭露 → 校訂答案 → 自我核對 → 註記錯漏 → 評分安排複習。

【備份／還原】
右上「匯出備份」下載包含 tb-v1、tb-essay-draft-v1、tb-essay-errors-v1 的本機 JSON。
把 JSON 傳到另一裝置後按「匯入備份」選擇。衝突同題以匯入版本為準，不相干題目保留。
備份可能含個人讀書草稿，請勿公開分享；系統不會上傳這份檔案。

【版本】
正式版 tb-2026-10-20e（以 i 版為底，35題中17題依校訂稿 d 版修正；20e 全面複核 ChatGPT 修改）。舊版封存於雲端「03_版本封存」。

【實測／限制】
已在 Chromium（390px）測試 PWA 與離線單檔；使用者 2026-10-20 以離線單檔於手機實測無誤後上線。
