申論記憶樹使用與資料安全

作答建議：先默寫→逐段揭露→核對完整答案→記下漏寫之處→評估回想程度。A/B/C 僅為複習優先順序，不是猜題命中機率。

備份：按「匯出備份」，會產生本機 JSON 檔，包含本裝置的熟練進度、申論草稿與錯漏註記；請自行保管，不要公開分享。

還原：按「匯入備份」選擇前述 JSON 檔；先經確認後合併本裝置的紀錄，同題衝突時以匯入檔案內容為準。匯入前請先匯出目前資料以防意外。

隱私：備份與匯入在本機執行，不傳送到伺服器；未按「儲存」的默寫或錯漏，只暫留於目前開啟的頁面記憶體，重整後可能遺失。

離線：使用 HTTPS 的正式或測試網站首次開啟並讓資料載入後，才能檢驗離線功能。直接雙擊 HTML 檔不等於已安裝 PWA。

法條全文：綠色虛底線的條號可點開全文（只連結寫明法名者，例如「刑法第302條」「刑訴§230」）；「法條」分頁可依條號或關鍵字查詢、背誦模式遮住條文、連續朗讀。

朗讀：使用裝置內建語音（需中文語音包；離線可用與否依裝置）。底部控制列可暫停、上下段、調語速與「題答間停頓」，停頓時間就是自我回想時間。

挖空回想：申論答案可遮住條號、判決字號與時限數字，先想再點，點開即計入已揭示。
