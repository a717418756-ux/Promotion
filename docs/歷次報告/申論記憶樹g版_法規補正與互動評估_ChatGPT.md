# 115年升官等｜申論記憶樹 g 版補強查核報告

版本：`tb-2026-10-18g_ChatGPT`（2026-10-18）；沿用 35 題第五版 + f 版已校訂答案；不取代原始題目或正式 d 版。

## 一、已核實法規並補充的差異

### 1. 刑事訴訟法預測第1題：無令狀搜索
- **f 版缺口**：把《刑事訴訟法》第131條第1項一概記成「找人」，未在申論答案列出第三款「有明顯事實足信有人在內犯罪而情形急迫」。
- **g 版處理**：直接拆成第1項三款：①逮捕、拘提或羈押確信人在內；②追躡現行犯或逮捕脫逃人確信人在內；③有人在內犯罪、明顯事實且情況急迫。第三款不等於「找人」。題幹甲已在押，無其他急迫事實，不能以第1項合理化入宅搜索。
- **區分第2項**：檢察官偵查中認為情況急迫且24小時內證據有偽造、變造、湮滅或隱匿之虞，得親自或指揮警察執行，不是司法警察獨立依第2項發動。
- **陳報程序**：檢察官執行應於3日內陳報法院；警察等執行應於3日內報告檢察官及法院；法院認不應准許者應於5日內撤銷。未陳報或經撤銷，審判法院得排除扣得物證據能力。
- **查證法源**：《刑事訴訟法》第130、131、131-1條（法務部全國法規資料庫）：https://law.moj.gov.tw/LawClass/LawAll.aspx?pcode=C0010001

### 2. 刑事訴訟法預測第3題：GPS定位科技偵查
- **f 版缺口**：提及24小時／2日與30日上限，未在申論答案寫出「實施當日不足24小時，以一日計」、延長許可的聲請時點。
- **g 版處理**：補明第153條之1第3～5項之規定：預計超出門檻可事前聲請、需再次實施最遲再次實施前聲請、繼續實施須在期間屆滿前聲請；法院許可每次最多30日，續行應在期滿二日前聲請。急迫時的補發仍按第153條之6另外判斷。
- **查證法源**：《刑事訴訟法》第153-1、153-6、153-8、153-10條（法務部全國法規資料庫）：https://law.moj.gov.tw/LawClass/LawAll.aspx?pcode=C0010001

**校訂邊界**：以上是法條文本補強，不表示已重新逐條驗證其他33題全部事實、判例及政策名稱；它們繼續沿用 f 版，原有⚠照留。

## 二、從「看過」提升為「寫得出來」的介面修改

1. **先默寫再對答案**：35題題幹下新增繁體中文草稿區。輸入不會立即自動上傳或持久化；必須按「僅儲存在此裝置」才寫入瀏覽器的 `tb-essay-draft-v1`，支援複製、清除。每題最多5000字，不與原有 `tb-v1` 熟練紀錄混用。
2. **骨架自我檢核**：答案顯示後提供每段對照勾選，讓使用者檢查是否能不看答案寫出法源、要件、涵攝與結論。勾選並非AI閱卷、不等於正式分數。
3. **六組流程圖逐格揭露**：保留 f 版六套視覺素材，不另編故事；改為遮住細節→先腦內回想→揭露一格→全部展示。動態效果遵從電子紙模式及 `prefers-reduced-motion`。
4. **隨機抽題**：限定於當前科目與篩選條件，降低按題號順序背熟卻難以看到題幹就回想的風險。
5. **獨立背誦紙本**：從已有的 35 題資料產出「題幹與骨架分開自測」Markdown，適合離線、BOOX 及列印。

## 三、PWA 快取安全性

- **f 版風險**：Service Worker 的 `activate` 會刪除同一網域下除本版版本名稱以外所有快取，不論是否屬於記憶樹。在同網域設置其他 PWA 時可能互相干擾。
- **g 版**：仍保留 `const V = 'tb-2026-10-18g'`，CacheStorage 使用 `promotion-` 專案前綴，只刪除舊的 `promotion-` 快取。請注意以前的無前綴 `tb-` 快取可能殘留，不會在本版擅自刪除。對外部網域或非本專案 scope 的 GET 請求不再攔截快取。
- **版本與路徑**：所有部署資產保持 `index.html`、`sw.js`、`manifest.webmanifest`、`icons/`、`data/` 原始路徑，不需重新命名內部檔案。
